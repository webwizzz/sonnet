### Gotchas

- **Background crop**: the image fill is STRETCH with an `imageTransform` (scale 0.958 × 0.735, offset 0.0103 / 0.169). Only the source area x 7.8–731 px and y 73.4–392.6 px (of 755 × 434) is visible, cropped to the 1920 × 847 ratio. Plain `object-fit: cover` centers differently and does not apply Figma's extra 1.04× zoom. `object-position: center 64%` gets close; for an exact match, pre-crop the asset to x 8–731 / y 73–393.
- **Low-resolution background**: the exported PNG is only **755 × 434**, and it is shown at 1920 wide (about 2.5× upscale), so it will look soft. Ask for a source of at least 2400px.
- **Overlay order**: the 20% `#28201F` is **above** the image (it is the second fill in Figma's bottom-to-top order). Render it as an `::after` overlay.
- **Union shape**: the white backdrop is a BOOLEAN_OPERATION (Union) of 5 capsules. One of them (191:548) is a VECTOR with a 313 × 431 vector network inside a 313 × 450 box. Ignore it and build 5 identical CSS capsules.
- **Radius 642.61**: an odd Figma value. It means fully rounded, so the effective radius is 156.5px.
- **Rotation −0.0 / −7.3e-17** on the capsule rectangles is float noise. Ignore it.
- **Mixed-style heading**: one TEXT node with 2 runs. "The science behind" plus the space after it is Blauer Nue 500. "the results." is Tiempos **400** italic (`'Test Tiempos Fine Italic RG'`, not the 500 italic used for the percentages). The heading line-height is **110%** (63.8px), tighter than the ~120% used in other section headings.
- **Percent alignment**: "6%" is LEFT-aligned in Figma while the others are CENTER. Every box is auto-width and centered on its pill anyway, so treat them all as centered.
- **Weight 200 = `'Blauer Nue TH'`**: in `assets/home-tlpc.css` the TH face uses a file called "Blauer-Nue-Thin" but is declared `font-weight: 200`. That matches the README mapping, but the glyphs may look slightly thinner than Figma's ExtraLight.
- **Body copy quirks**: the dashes are em dashes (—). Pill 5 has inconsistent spacing around the hyphens ("Parabens- Phthalates-Alcohol -Mineral Oil-Petrolatum-Propylene Glycol"). Keep the copy as-is unless the client changes it.
- Each 50 × 50 glyph frame has a **hidden** white fill (`visible: false`). Ignore it; the frames are transparent.
- **Existing theme section**: `sections/science-cards.liquid` ("Science Cards", with `sc__bg`, `sc__bg-overlay`) already exists. Check whether it already implements this layout before creating a new section.
