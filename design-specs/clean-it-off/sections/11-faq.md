### Gotchas

- **Item number font is not loaded**: Test Tiempos Fine **SemiBold Italic (600)** is not in `assets/home-tlpc.css`. The fallback `'Test Tiempos Fine Italic'` (500) looks slightly lighter. Upload a SemiBold Italic woff2 for an exact match.
- **Text colour `#010101`**: the questions and answers use near-black `#010101`, **not** the page text colour `#28201F`. The toggle stroke is also `#010101` at 10%.
- **Letter-spacing 0**: the item texts use **0** letter-spacing (the node tree prints "ls Nonepx"; the raw value is 0.0). The heading keeps -0.02em.
- **Mixed-style heading**: one TEXT node. "Everything you want to" is Blauer Nue 500. **" know first."**, including the leading space, is Tiempos 400 italic. Line-heights differ per run (69.58 vs 70.3).
- **Open vs closed offsets differ**: in the open item the question top moves from +45 to **+32** and the toggle from +32 to **+29**. The toggle is therefore **not** vertically centered on the question line (question center +47, toggle center +57).
  - The number sits 3px below the question top in closed items (+48 vs +45) but level with it in the open item (+32).
  - Building with `align-items: center` on a header row of fixed height ~94px (32 + 30 + 32) reproduces the closed state. Then add `padding-bottom: 38px` for the panel when open.
- **Radius jump**: closed radius 500 (effectively 60) vs open radius 36. Animate `border-radius` together with the height, or the corners will snap.
- **Minus icon structure**: the open-state glyph frame is **rotated −45°** (−0.785 rad, 33.94 × 33.94 bounding box), with a single line also rotated −45°, which cancels out to a horizontal line. It looks like a plain minus. Do not copy the rotation; use the exported SVG 191-898.
