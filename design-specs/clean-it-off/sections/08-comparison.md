### Gotchas

- **Hidden drop shadow** on the tube image (191:495, `visible: false`). Do not port it.
- **The heading has an explicit line break** ("What makes it⏎different from others"), and the italic run starts exactly at line 2. Use `<br>` or two `<p>`/`<span>` lines in the richtext.
- **"OTHER BRANDS" is typed in capitals** with no textCase. Uppercasing it via CSS is harmless if you store natural case.
- **Inconsistent column-1 width:** "Live postbiotic actives" is 156 px wide while the other columns are 140 px. Use a uniform 140 px column; it still wraps the same way.
- **Row rectangles repeat the card fill** `#F5EEE6`. Do not give rows a separate background or the card radius.
- **Row 1 has both top and bottom borders; row 2 has only a bottom border.** Don't double the middle line.
- **The two brand cells use different insets:** the tube starts at x 219, the bottle image at x 200. The bottle PNG has transparent padding, so both look aligned in the render. Keep the image boxes as-is, or add about 19 px of left padding to the competitor image if you swap in a tightly cropped image.
- **The logo and competitor images are cropped by imageTransforms.** Merchant uploads should be pre-cropped. Use `object-fit: contain` for the logo and `cover` for the bottle.
- **The X stroke is 1 px and the check stroke is 1.5 px.** This is intentional in the design, so don't normalise them.
- **The heading uses 40 px** (smaller than the 58 px headings in sections 05–07).
- **Group 191:484 and its child 191:485 are both 1720 × 540**, so one wrapper is redundant. Build a single card element.
